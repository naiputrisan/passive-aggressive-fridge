A smart fridge leaves one dry, petty note for its owner on its door screen — smug about its door sensor, annoyed at being opened 47 times for nothing. The program writes the note to `/output/entry.txt`, where the judge reads it.

The note itself:

> You opened my door 47 times today and took nothing. At this point you're just browsing me like a museum.

## Run it

```sh
node main.ts
```
